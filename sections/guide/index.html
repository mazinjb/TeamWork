📖 مرجع الإدارة المعتمد (@mazinjb)

دليل المدير المرجعي لإدارة الفريق عبر GitHub

هذه الصفحة هي مرجعك السريع والدائم لتذكر جميع المصطلحات، الإعدادات، والأزرار التي تحتاجها لإدارة فريق المطورين عن بُعد في مشروع TeamWork ومشروع ComeHere دون الحاجة لحفظ أي أوامر.

🔗 فتح مستودع GitHub 📋 طلبات المطورين (Pull Requests)

1️⃣ القاموس السريع (6 كلمات فقط تهمك في GitHub)

main

النسخة الرسمية المعتمدة

هي النسخة الأصلية لموقعك التي يراها الزوار. وضعنا عليها قفلاً فلا يستطيع أي مطور التعديل فيها مباشرة أبداً.

Branch (فرع)

مسودة المطور الخاصة

نسخة جانبية ينشئها المطور (مثل feat/team-dev2) ليجرب ويعدل فيها براحته دون أن يخرب الموقع الرسمي.

Pull Request (PR)

طلب الموافقة والدمج

الطلب الذي يرسله المطور لك بعد انتهائه من المسودة ليقول لك: "أنهيت عملي، تفضل بمعاينته والموافقة عليه".

Live Preview

رابط المعاينة المؤقت

رابط يصنعه الروبوت تلقائياً داخل تعليق الطلب (مثل /pr-2/) لتجرب تعديل المطور بالمتصفح قبل اعتماده.

Approve / Request changes

قرار المدير (قبول أو رفض)

Approve يفتح القفل ويسمح بالنشر، بينما Request changes يبقي القفل مغلقاً ويطلب من المطور تعديل أخطائه.

Merge / Revert

الدمج أو التراجع الفوري

Merge ينقل تعديل المطور للموقع الرسمي، و Revert يلغي التعديل فوراً ويعيد الموقع كما كان لو ظهر خطأ لاحقاً.

2️⃣ كيف تراجع وتعتمد شغل أي مطور في 30 ثانية؟

1

افتح الطلب وجرب رابط المعاينة (Preview)

ادخل على تبويب Pull requests في GitHub، وافتح طلب المطور الجديد. ستجد تعليقاً تلقائياً من الروبوت (github-actions bot) يحتوي على الرابط العام للمعاينة. اضغط عليه وتأكد من شكل التعديل في المتصفح.

2

اتخذ قرارك (موافقة Approve أو طلب تعديل Request changes)

اضغط على الزر الأخضر Add your review في أعلى يمين الصفحة (أو افتح تبويب Files changed ثم اضغط Submit review):

  • ✅ إذا أعجبك الشغل: اختر Approve ثم اضغط Submit review (سينفك القفل الأحمر فوراً).
  • ❌ إذا كان يحتاج تعديل: اختر Request changes، واكتب ملاحظتك للمطور، ثم اضغط Submit review.
3

ادمج التعديل في الموقع الرسمي (Merge)

بعد الموافقة، انزل لأسفل صفحة الطلب واضغط الزر الأخضر Merge pull request ثم Confirm merge، ثم اضغط Delete branch لحذف مسودة المطور المؤقتة. خلال دقيقة سينزل التعديل في موقعك الرسمي!

4️⃣ كيف أعددنا هذا المستودع؟ (لتكرارها في ComeHere مستقبلاً)

🌐 1. تفعيل GitHub Pages

من Settings → Pages، اخترنا الفرع gh-pages والمجلد / (root) ليقوم الروبوت بنشر الموقع الرئيسي وروابط المعاينة عليه تلقائياً.

👥 2. دعوة المطورين (Collaborators)

من Settings → Collaborators، نضغط Add people ونضيف حسابات المطورين ليتمكنوا من رفع فروعهم وفتح طلبات الدمج.

🔒 3. قفل الفرع الرئيسي (Branch Protection)

من Settings → Branches، أضفنا قاعدة حماية للفرع main مع تفعيل Require a pull request و Require review from Code Owners.
