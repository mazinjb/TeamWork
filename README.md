# 🚀 مشروع TeamWork – تجربة إدارة فريق تطوير عن بُعد عبر GitHub

**الهدف:** نموذج عملي (Proof of Concept) لإدارة فريق تطوير عن بُعد باستخدام GitHub (فروع مستقلة، مراجعة الكود عبر `CODEOWNERS`، ومعاينات حية لكل Pull Request عبر `GitHub Pages`) قبل تطبيقه على مشروع **ComeHere**.

---

## 🌐 الروابط الحية للمشروع
- **الموقع الرئيسي (النسخة المعتمدة - `main`):**
  `https://mazinjb.github.io/TeamWork/`
- **روابط معاينة التعديلات (PR Previews):**
  عند فتح أي Pull Request برقم `X`، يتم توليد رابط معاينة تلقائي على المسار:
  `https://mazinjb.github.io/TeamWork/pr-X/`

## 📂 هيكل المستودع وتوزيع المهام على المطورين

تم عزل كل قسم من أقسام الموقع الأربعة في مجلد مستقل تماماً لضمان عدم حدوث تعارض في الكود (Merge Conflicts) ولتطبيق قواعد ملكية الكود بدقة:

| القسم | المسار المخصص للمطور | الوصف | المسؤول العام عن الاعتماد |
| :--- | :--- | :--- | :--- |
| **1. Home (الرئيسية)** | `sections/home/` | الصفحة الترحيبية ونظرة عامة على المنصة | `@mazinjb` |
| **2. Team (الفريق)** | `sections/team/` | استعراض أعضاء الفريق وتوزيع الأدوار | `@mazinjb` |
| **3. Services (الخدمات)** | `sections/services/` | عرض الخدمات التقنية ومنظومة العمل | `@mazinjb` |
| **4. Contact (التواصل)** | `sections/contact/` | نموذج التواصل وقنوات المتابعة | `@mazinjb` |
| **الملفات المشتركة** | `shared/` و `.github/` | شريط التنقل الموحد وإعدادات الأتمتة (خاص بالمسؤول) | `@mazinjb` |

## 🔄 دورة عمل المطور خطوة بخطوة (Developer Workflow)

يجب على كل مطور الالتزام بالخطوات التالية عند تنفيذ أي تعديل في قسمه:

### 1. سحب أحدث نسخة وإنشاء فرع مستقل (Branch)
</div>

<div dir="ltr" align="left">

```bash
git checkout main
git pull origin main
git checkout -b feat/home-update   # استبدل الاسم باسم قسمك والتعديل
```

</div>

<div dir="rtl" align="right">

### 2. تنفيذ التعديل والاختبار محلياً
- عدّل الملفات الموجودة **داخل مجلد قسمك فقط** (مثلاً `sections/home/`).
- افتح ملف `index.html` في المتصفح على جهازك وتأكد من سلامة التصميم وعدم وجود أخطاء.

### 3. رفع التعديل إلى GitHub
</div>

<div dir="ltr" align="left">

```bash
git add sections/home/
git commit -m "تحديث قسم الرئيسية وإضافة البطاقات التعريفية"
git push -u origin feat/home-update
```

</div>

<div dir="rtl" align="right">

### 4. فتح طلب دمج (Pull Request) ومعاينة التعديل
1. من صفحة المستودع على GitHub، اضغط **Compare & pull request** باتجاه الفرع `main`.
2. سيقوم نظام **GitHub Actions** تلقائياً بـ:
   - فحص أنك لم تقم بتعديل أقسام المطورين الآخرين (`Scope Check`).
   - بناء **نسخة معاينة حية (Live Preview)** وكتابة تعليق تلقائي داخل الـ PR يحتوي على رابط المعاينة المباشر.
3. يقوم المسؤول العام (`@mazinjb`) بفتح رابط المعاينة وتجربة التعديل:
   - إذا طلب تعديلات (`Request Changes`): نفذها في نفس الفرع وارفعها (`git push`) وستتحدث المعاينة تلقائياً.
   - إذا وافق (`Approve`): يتم دمج التعديل (`Merge`) في الموقع الرئيسي وحذف نسخة المعاينة المؤقتة تلقائياً.

</div>
